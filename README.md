# csedit
A simple terminal text editor built on C# and .NET 10. Influenced by [kilo](https://viewsourcecode.org/snaptoken/kilo/) and [this](https://codereview.stackexchange.com/questions/191503/simple-console-text-editor) code review post on Stack Exchange.

> [!NOTE]
> No generative AI was (or will be) involved in the making of this project.

## Installation and usage
Download the executable from the Releases page (currently supports macOS).

To create a new text file, run:
```
csedit
```

To open an existing file:
```
csedit <filename>
```

## Keybindings
- `Ctrl+S`: Save buffer to file
- `Ctrl+Q`: Exit
